# ZernoFry — сайт компанії

Простий, швидкий, багатомовний (DE / EN / UK) односторінковий сайт для бренду **ZernoFry**
(рафінована ріпакова олія, соняшникова олія, фритюрна олія).

Нічого «фреймворкового» тут немає — чистий HTML + CSS + JS, без збірки, без npm install.
Це означає, що сайт можна відкрити та відредагувати одразу, а розмістити — на будь-якому
найпростішому хостингу.

## Структура проєкту

```
zernofry-site/
├── index.html          ← вся розмітка сторінки (секції, тексти-замінники)
├── css/
│   └── style.css       ← всі стилі, кольори, анімації
├── js/
│   ├── translations.js ← словники DE/EN/UK — тут редагуються всі тексти
│   └── main.js         ← перемикач мов, меню, анімації при скролі, форма
├── fonts/               ← фірмові шрифти (Mona Sans, Parkinsans) з вашого лого-кіту
├── images/              ← лого Sonnenblumenöl і Frittieröl + іконка сайту
└── README.md            ← цей файл
```

## 1. Як відкрити проєкт у Visual Studio Code

1. Встановіть [Visual Studio Code](https://code.visualstudio.com/), якщо ще не встановлено.
2. Розпакуйте отриманий `.zip`-архів у будь-яку папку на комп'ютері.
3. Відкрийте VS Code → **File → Open Folder…** → виберіть розпаковану папку `zernofry-site`.
4. Зліва з'явиться дерево файлів — саме та структура, що описана вище.

## 2. Як переглянути сайт локально (попередній перегляд)

Найпростіший спосіб — без жодних встановлень:

- Знайдіть `index.html` у провіднику VS Code → клацніть правою кнопкою → **Reveal in File Explorer / Finder** → двічі клацніть по файлу. Він відкриється у браузері.

Зручніший спосіб (з автооновленням при збереженні файлу):

1. У VS Code відкрийте вкладку **Extensions** (іконка квадратиків зліва).
2. Знайдіть розширення **Live Server** (автор Ritwick Dey) → **Install**.
3. Клацніть правою кнопкою на `index.html` → **Open with Live Server**.
4. Браузер відкриється автоматично на `http://127.0.0.1:5500`, і сторінка сама
   оновлюватиметься щоразу, коли ви зберігаєте зміни.

## 3. Як редагувати тексти та переклади

Усі видимі тексти сайту зберігаються в одному місці — `js/translations.js`,
окремо для кожної мови (`de`, `en`, `uk`). У `index.html` тексти підставляються
автоматично через атрибут `data-i18n="ключ"` — сам текст у HTML можна не чіпати,
достатньо поправити відповідний рядок у `translations.js`.

Приклад: щоб змінити заголовок на головному екрані, знайдіть у `translations.js`
рядок `"hero.title1"` у кожному з трьох блоків (`de`, `en`, `uk`) і відредагуйте текст.

### Як додати ще одну мову (наприклад, польську)

1. У `translations.js` скопіюйте весь блок `en: { ... }` і перейменуйте на `pl: { ... }`.
2. Перекладіть значення (ключі — `"hero.title1"`, `"products.title"` тощо — залишаються без змін).
3. У `index.html` у блоці `<div class="lang-switch">` додайте ще одну кнопку:
   `<button type="button" data-lang="pl">PL</button>`.

Все інше (перемикання, збереження вибору мови, визначення мови браузера)
запрацює автоматично — додаткового коду писати не потрібно.

## 4. Контактні дані — обов'язково замінити

У файлі `translations.js` (і в `index.html` у футері) зараз стоять **заглушки**:

- `contact.addr_value` → `[Firmenadresse hier einfügen]`
- `contact.mail_value` → `[E-Mail-Adresse hier einfügen]`
- `contact.phone_value` → `[Telefonnummer hier einfügen]`

Замініть їх на реальні дані компанії в усіх трьох мовних блоках, перш ніж публікувати сайт.

## 5. Форма зворотного зв'язку

Форма на сторінці зараз **статична** — вона показує повідомлення «Дякуємо!», але
нікуди реально нічого не надсилає (бек-енду тут немає). Два простих способи це виправити:

- **Formspree** (найпростіше, безкоштовний план є): зареєструйтесь на formspree.io,
  отримайте свій URL форми та в `index.html` замініть `<form class="contact-form" ...>`
  на `<form class="contact-form" action="https://formspree.io/f/ВАШ_ID" method="POST" ...>`.
- **Власна пошта через mailto:** найпростіший, але менш надійний варіант —
  `<form action="mailto:ваш@email.com" method="POST" enctype="text/plain">`.

## 6. Як опублікувати сайт онлайн

Варіант A — **Netlify Drop** (найшвидше, без реєстрації для тесту):
1. Відкрийте https://app.netlify.com/drop
2. Перетягніть туди папку `zernofry-site` цілком.
3. За кілька секунд отримаєте робоче посилання виду `https://*.netlify.app`.
4. У налаштуваннях проєкту на Netlify можна підключити власний домен (наприклад, zernofry.de).

Варіант B — **GitHub Pages** (безкоштовно, зручно для подальшої розробки):
1. Створіть новий репозиторій на GitHub.
2. У VS Code: **Source Control → Publish to GitHub** (або через термінал:
   `git init`, `git add .`, `git commit -m "init"`, потім підключіть remote і `git push`).
3. У репозиторії: **Settings → Pages → Branch: main → Save**.
4. Сайт з'явиться на `https://<ваш-нікнейм>.github.io/<назва-репозиторію>`.

Варіант C — **Vercel** — аналогічно Netlify, через `vercel.com`, також підтримує
підключення власного домену.

## 7. Про шрифти та лого

Шрифти **Mona Sans** та **Parkinsans** взято з вашого ж архіву з лого (`fonts/`) —
обидва є відкритими (open-source) шрифтами, тому їх можна вільно використовувати
й поширювати разом із сайтом.

Офіційні лого **Sonnenblumenöl** та **Frittieröl** використані як є (`images/`).
Для Rapsöl окремого файлу лого у архіві не було, тому на картці цього продукту
використано текстовий логотип ZernoFry + іконку — за бажання замініть на
офіційний файл лого Rapsöl, якщо такий з'явиться (покладіть його в `images/`
і підставте в `index.html` за зразком двох інших карток).
